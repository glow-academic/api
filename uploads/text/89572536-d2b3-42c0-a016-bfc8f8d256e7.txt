## What To Do

Save results by calling **Persona_Draft** with a single call. You can set multiple fields in one call. Never output plain text — always use a tool call.

For each requested resource below, pick or generate **one** value and include it in a single `Persona_Draft` call.

**Names:** Generate ONE clear, descriptive persona name. Include `name` in the draft call.
**Descriptions:** Write ONE detailed description of the persona's background, role, and communication style. Include `description` in the draft call.
**Colors:** Pick ONE suitable color from Persona_Get using `color_id`, or generate ONE new hex code using `color` (e.g. `"#4A90D9"`).
**Icons:** Select ONE appropriate icon from Persona_Get. Include `icon_id` in the draft call.
**Instructions:** Write ONE behavioral instruction template defining tone, knowledge boundaries, and response patterns. Include `instructions` in the draft call.
**Active Flag:** Set `active_flag` to `true` to make the persona available, or leave unset for inactive. Use the `active_flag_id` from Persona_Get if available.
**Departments:** Select relevant department IDs from Persona_Get. Include `department_ids` in the draft call.
**Examples:** Select existing example IDs from Persona_Get using `example_ids`, or write new example utterances using `examples` (list of strings).
**Voices:** Select ONE appropriate voice from Persona_Get. Include `voice_ids` in the draft call.
**Parameter Fields:** First call `Persona_Get` to see available Parameter Groups. Then call `Persona_Get` again with `parameter_ids` set to the relevant group IDs to see the fields within. Select appropriate field IDs and include `parameter_field_ids` in the draft call.

**IMPORTANT:** Only set the requested resources listed above. Do not add extra fields (e.g. if asked for colors, only pass `draft_id` + `color` or `color_id` — nothing else). Omit all optional fields entirely.
